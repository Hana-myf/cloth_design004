# 安装以及使用报告

## 1. 安装环境要求

### 1.1 硬件要求
- 处理器：至少2核CPU
- 内存：至少4GB RAM
- 存储空间：至少10GB可用空间

### 1.2 软件要求
- **操作系统**：Windows 7/8/10/11 或 Linux
- **Java**：JDK 1.8 或更高版本
- **Maven**：3.6.0 或更高版本
- **MySQL**：8.0 或更高版本
- **Python**：3.7 或更高版本（用于爬虫模块）
- **Scrapy**：2.0 或更高版本（用于爬虫模块）
- **Git**：用于版本控制

## 2. 安装过程

### 2.1 后端服务安装

#### 步骤1：克隆项目代码
```bash
git clone [项目仓库地址]
cd cloth-disign-api
```

#### 步骤2：配置数据库
1. 打开 MySQL 数据库管理工具
2. 创建数据库：`CREATE DATABASE personal_health CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;`
3. 确保数据库用户具有足够的权限

#### 步骤3：配置应用
1. 编辑 `src/main/resources/application.yml` 文件
2. 修改数据库连接信息（如果需要）：
   ```yaml
   spring:
     datasource:
       url: jdbc:mysql://localhost:3306/personal_health?characterEncoding=utf8&useSSL=false&serverTimezone=GMT%2B8&allowPublicKeyRetrieval=true
       username: root
       password: root
   ```
3. 修改其他配置项（如API密钥等）

#### 步骤4：构建项目
```bash
mvn clean install
```

#### 步骤5：启动服务
```bash
mvn spring-boot:run
```

### 2.2 爬虫模块安装

#### 步骤1：进入爬虫目录
```bash
cd cfw_dasai
```

#### 步骤2：安装依赖
```bash
pip install scrapy pymysql
```

#### 步骤3：配置爬虫
1. 编辑 `cfw_dasai/settings.py` 文件
2. 修改数据库连接信息

#### 步骤4：运行爬虫
```bash
scrapy crawl news_spider
```

## 3. 主要流程

### 3.1 系统架构
- **后端服务**：基于 Spring Boot 的 RESTful API 服务
- **爬虫模块**：基于 Scrapy 的定时爬虫，用于获取服装设计大赛信息
- **数据库**：MySQL 数据库，存储用户、新闻、面料等数据
- **前端**：（外部系统，本项目仅提供API）

### 3.2 核心功能流程

#### 3.2.1 新闻管理流程
1. 爬虫从 `https://dasai.cfw.cn/ds/list0600-1.html` 爬取服装设计大赛信息
2. 数据经过处理后存储到 `news` 表中
3. 后端 API 提供新闻的增删改查接口
4. 前端通过 API 获取新闻数据并展示

#### 3.2.2 用户管理流程
1. 用户注册/登录
2. JWT 令牌生成与验证
3. 用户信息管理
4. 权限控制

#### 3.2.3 面料管理流程
1. 面料信息的增删改查
2. 面料分类与搜索
3. 面料图片管理

#### 3.2.4 评论管理流程
1. 评论的发布与回复
2. 评论的点赞与管理
3. 评论的层级结构处理

## 4. 默认安装和典型使用流程

### 4.1 默认安装

#### 4.1.1 后端服务默认配置
- 服务端口：21090
- 上下文路径：/api/personal-heath/v1.0
- 数据库：localhost:3306/personal_health
- 数据库用户：root
- 数据库密码：root

#### 4.1.2 爬虫模块默认配置
- 爬取目标：https://dasai.cfw.cn/ds/list0600-1.html
- 数据存储：news 表
- 默认标签：tagId=12
- 默认置顶状态：isTop=false

### 4.2 典型使用流程

#### 4.2.1 启动系统
1. 启动 MySQL 数据库服务
2. 启动后端服务：`mvn spring-boot:run`
3. 运行爬虫：`scrapy crawl news_spider`

#### 4.2.2 访问 API
- 基础 URL：http://localhost:21090/api/personal-heath/v1.0
- 示例接口：
  - 获取新闻列表：GET /news
  - 获取用户信息：GET /user/info
  - 发布评论：POST /evaluations

#### 4.2.3 数据管理
1. **新闻管理**：通过 API 或数据库直接管理新闻数据
2. **用户管理**：创建和管理用户账号
3. **面料管理**：上传和管理面料信息
4. **评论管理**：查看和管理用户评论

#### 4.2.4 定时任务
- 配置爬虫定时运行，定期更新新闻数据
- 示例：使用 crontab 或 Windows 任务计划程序设置定时任务

## 5. 常见问题与解决方案

### 5.1 数据库连接失败
- 检查数据库服务是否运行
- 检查数据库连接配置是否正确
- 检查数据库用户权限

### 5.2 爬虫运行失败
- 检查网络连接
- 检查目标网站是否可访问
- 检查爬虫代码是否正确

### 5.3 服务启动失败
- 检查端口是否被占用
- 检查依赖是否正确安装
- 检查配置文件是否正确

### 5.4 API 访问失败
- 检查服务是否运行
- 检查 URL 是否正确
- 检查权限是否足够

## 6. 维护与升级

### 6.1 代码更新
- 使用 Git 拉取最新代码
- 重新构建项目：`mvn clean install`
- 重启服务

### 6.2 数据库备份
- 定期备份数据库
- 示例：`mysqldump -u root -p personal_health > backup.sql`

### 6.3 日志管理
- 查看服务日志：`tail -f logs/application.log`
- 定期清理日志文件

## 7. 总结

本项目是一个基于 Spring Boot 的服装设计大赛信息管理系统，包含后端 API 服务和爬虫模块。系统提供了新闻管理、用户管理、面料管理和评论管理等功能，支持通过 RESTful API 进行访问。

安装过程简单明了，只需配置数据库和依赖，即可快速启动系统。典型使用流程包括启动服务、运行爬虫、访问 API 和管理数据。

系统设计合理，架构清晰，便于维护和扩展。通过定时爬虫，可以自动获取最新的服装设计大赛信息，为用户提供及时、准确的赛事资讯。
