# 定时爬虫汇总报告

## 1. 爬虫概述

### 1.1 功能描述
- **爬取目标**：`https://dasai.cfw.cn/ds/list0600-1.html` 服装设计大赛信息
- **数据内容**：赛事标题、封面图片、比赛时间、详细内容
- **数据存储**：MySQL数据库 `news` 表
- **过滤规则**：只爬取未截止的比赛
- **数据处理**：保持详细内容的段落结构，设置默认标签和置顶状态

### 1.2 技术栈
- **爬虫框架**：Scrapy 2.0+
- **数据存储**：MySQL 8.0+
- **连接库**：pymysql
- **定时调度**：Windows任务计划程序 / Python调度库

## 2. 爬虫实现

### 2.1 核心文件
- **`news_spider.py`**：爬虫主逻辑，负责从目标网站提取赛事数据
- **`items.py`**：定义数据结构，与数据库表结构对应
- **`pipelines.py`**：处理数据存储，实现插入和更新逻辑
- **`settings.py`**：爬虫配置，包括数据库连接信息

### 2.2 关键功能
1. **数据提取**：使用XPath提取页面元素，包括标题、封面图片、详情链接、比赛时间和详细内容
2. **数据过滤**：解析比赛时间，与当前日期比较，只保留未截止的比赛
3. **数据存储**：存储到MySQL数据库的`news`表，支持更新已有记录
4. **错误处理**：捕获并记录解析错误，处理日期解析异常

### 2.3 运行流程
1. 从起始URL开始，提取赛事列表
2. 对每个赛事，提取封面图片和详情链接
3. 访问详情链接，提取比赛时间和详细内容
4. 检查比赛是否未截止
5. 存储或更新数据到数据库
6. 提取下一页链接，继续爬取

## 3. 定时调度方案

### 3.1 方案一：Windows任务计划程序

#### 实现步骤
1. **创建批处理文件**：
   ```batch
   @echo off
   cd /d d:\web\cloth_design\cloth-disign-api\cfw_dasai
   python run_spider.py
   ```

2. **设置任务计划**：
   - 打开任务计划程序
   - 创建基本任务，设置名称和描述
   - 选择触发频率（如每天）
   - 设置开始时间（如凌晨2:00）
   - 操作选择"启动程序"
   - 选择批处理文件路径

#### 优势
- 系统级调度，可靠性高
- 无需额外依赖
- 适合Windows环境

### 3.2 方案二：Python调度库

#### 实现步骤
1. **安装依赖**：
   ```bash
   pip install apscheduler
   ```

2. **创建调度脚本**：
   ```python
   from apscheduler.schedulers.blocking import BlockingScheduler
   import os
   import subprocess

   def run_spider():
       os.chdir('d:\\web\\cloth_design\\cloth-disign-api\\cfw_dasai')
       subprocess.run(['python', '-m', 'scrapy', 'crawl', 'news'])

   scheduler = BlockingScheduler()
   scheduler.add_job(run_spider, 'cron', hour=2, minute=0)
   scheduler.start()
   ```

#### 优势
- 跨平台支持
- 灵活的调度配置
- 易于集成到现有系统

### 3.3 方案三：Linux crontab

#### 实现步骤
1. **编辑crontab**：
   ```bash
   crontab -e
   ```

2. **添加定时任务**：
   ```bash
   # 每天凌晨2点运行爬虫
   0 2 * * * cd /path/to/cfw_dasai && python -m scrapy crawl news
   ```

#### 优势
- 适合Linux服务器环境
- 轻量级，资源占用少
- 配置简单
